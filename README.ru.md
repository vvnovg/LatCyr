# LatCyr

Приложение для строки меню macOS: автоматически определяет текст, набранный
в неправильной раскладке (Русский ↔ English), переключает раскладку и
исправляет набранное.

**Бинарную версию можно скачать здесь: https://github.com/vvnovg/LatCyr/releases/latest**

🇬🇧 [English version of the README](README.md)

## Скачать

**[LatCyr.zip — последняя тестовая сборка](https://github.com/vvnovg/LatCyr/releases/latest)**

Не релиз, версии нет — сборки помечаются коммитом, с которого собраны.

### Установить

1. Распакуй `LatCyr.zip`, перемести `LatCyr.app` в `/Applications`.
2. Открой через **правый клик → Открыть** (может потребоваться из-за
   ad-hoc подписи / Gatekeeper — обычный двойной клик покажет
   предупреждение «неизвестный разработчик»). Если Mac пишет «файл
   повреждён», сними карантинный атрибут:
   ```bash
   xattr -cr /Applications/LatCyr.app
   ```
3. Выдай разрешения **Accessibility** и **Input Monitoring** в
   System Settings → Privacy & Security, указав путь именно к
   `/Applications/LatCyr.app`.
4. Перезапусти приложение.

## Сборка

```bash
swift build
```

## Запуск

```bash
swift run LatCyr
```

Приложение живёт только в строке меню (без иконки в Dock), значок —
`character.cursor.ibeam`. При первом запуске, если разрешений не хватает,
показывается алерт и открываются Системные настройки. В самом меню:

- Переключатель — **LatCyr включено / выключено** — включает и выключает
  исправление без выхода из приложения.
- Актуальный статус разрешений — **✓/✗ Accessibility** и **✓/✗ Input
  Monitoring**.
- **Открыть настройки разрешений…** — сразу открывает раздел Privacy &
  Security.

Два необходимых разрешения:

1. **Accessibility** — чтобы читать и заменять текст в активном поле.
2. **Input Monitoring** — чтобы перехватывать нажатия клавиш.

Выдайте оба в System Settings → Privacy & Security, затем перезапустите
приложение. Переключатель не покажет «включено», пока хотя бы одного
разрешения не хватает.

> **Важно:** при запуске через `swift run` из терминала macOS приписывает
> запрос разрешений терминалу (как «ответственному процессу»), а не
> бинарнику LatCyr — выдача разрешения только бинарнику может не сработать.
> Для надёжной работы упакуйте приложение как `.app` (см. ниже).

## Упаковка в .app (рекомендуется)

Упакованное приложение имеет собственную TCC-идентичность, поэтому
разрешения применяются к самому LatCyr.app и работают независимо от способа
запуска.

```bash
./scripts/package-app.sh   # release-сборка + упаковка в dist/LatCyr.app (ad-hoc подпись)
open dist/LatCyr.app
```

Затем выдайте оба разрешения именно `dist/LatCyr.app` в System Settings →
Privacy & Security (Accessibility и Input Monitoring) и перезапустите
приложение.

> Повторный запуск `package-app.sh` переподписывает бандл, что меняет его
> code hash и сбрасывает уже выданные разрешения — после переупаковки нужно
> выдать их заново.

## Автозапуск при входе в систему

У LatCyr нет встроенного переключателя «запускать при входе» — используй
системные Login Items. Сначала перенеси приложение в постоянное место
(`/Applications`, а не `dist/` — это gitignore'нутая build-папка, которая
пересоздаётся при каждой сборке):

```bash
mv dist/LatCyr.app /Applications/LatCyr.app
```

Затем: System Settings → General → **Login Items & Extensions** → нажми
«+» под «Open at Login» → выбери `/Applications/LatCyr.app`.

Приложение работает только через menu bar (без иконки в Dock и без окон),
поэтому скрывать его при автозапуске отдельно не нужно.

> Если потом пересоберёшь через `package-app.sh`, скопируй новый
> `dist/LatCyr.app` поверх `/Applications/LatCyr.app` и выдай разрешения
> заново (переподпись их сбрасывает) — сам пункт в Login Items
> пересоздавать не нужно, он по-прежнему указывает на тот же путь.

## Как это работает

- `CGEventTap` перехватывает события `keyDown` и накапливает текущее слово.
- На границе слова (пробел, пунктуация, цифра, Enter) чистая эвристика
  решает, набрано ли слово в неправильной раскладке.
- Если да, слово заменяется через Accessibility API, а раскладка клавиатуры
  переключается через Text Input Sources API.
- При сильном сигнале по первым двум символам раскладка переключается сразу
  (проактивный режим).
- Исправление никогда не трогает собственный интерфейс LatCyr и парольные
  (secure) поля.
- Выход — через пункт меню (**Выход**) или `Cmd+Q`.

## Ограничения (v1)

- Чистая эвристика без словаря: редкие слова могут быть пропущены, а
  короткие слова (<3 символов) ретроактивно никогда не исправляются.
- Приложения, не отдающие текст через Accessibility API, пропускаются.
- Парольные поля никогда не трогаются.
