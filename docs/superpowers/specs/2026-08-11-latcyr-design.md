# LatCyr — Дизайн-документ

**Дата:** 2026-08-11
**Статус:** утверждён

## 1. Цель

macOS-приложение, которое автоматически определяет, что текст набирается в неправильной раскладке клавиатуры, переключает раскладку на правильный язык и исправляет уже набранный текст. Основной сценарий — русский текст, ошибочно набранный в английской раскладке.

## 2. Требования

- **Режим работы:** авто-исправление в реальном времени (как Punto Switcher).
- **Языки:** Русский ↔ Английский, двусторонняя конвертация.
- **Детекция:** эвристика по паттернам символов (без словаря).
- **UI:** menu bar приложение (иконка в строке меню).
- **Сборка:** Swift Package (`swift build`), без Xcode.
- **Срабатывание:** гибрид — мгновенное переключение по сильному сигналу первого символа + ретроактивное исправление по концу слова.

## 3. Архитектура

### Компоненты

| Компонент | Файл | Ответственность |
|---|---|---|
| AppDelegate | `AppDelegate.swift` | NSStatusItem, меню, переключатель вкл/выкл |
| InputMonitor | `InputMonitor.swift` | CGEventTap: перехват keyDown, буфер слова, границы слова |
| LayoutManager | `LayoutManager.swift` | TIS API: текущая раскладка, переключение, keycode → символ |
| TextConverter | `TextConverter.swift` | Чистая функция: ЙЦУКЕН ↔ QWERTY, сохранение регистра |
| LanguageDetector | `LanguageDetector.swift` | Чистая функция: оценка «русскости»/«английскости», решение |
| TextFieldController | `TextFieldController.swift` | AX API: сфокусированное поле, чтение/замена текста |
| PermissionManager | `PermissionManager.swift` | Проверка/запрос разрешений Accessibility и Input Monitoring |

### Поток данных

1. Пользователь печатает → CGEventTap ловит `keyDown`.
2. InputMonitor определяет символ (keycode → символ через LayoutManager) и добавляет в буфер слова.
3. **Проактивный путь:** если первый символ — сильный сигнал другой раскладки → LayoutManager мгновенно переключает раскладку.
4. **Ретроактивный путь:** на границе слова (пробел, знак препинания, Enter) → LanguageDetector оценивает слово → если набрано не в той раскладке → TextFieldController заменяет слово, LayoutManager переключает раскладку.

### Принцип изоляции

TextConverter и LanguageDetector — чистые функции без системных зависимостей, полностью юнит-тестируемые. Компоненты, работающие с системными API (CGEventTap, TIS, AX), — тонкие обёртки.

## 4. Конвертация (TextConverter)

Двусторонняя таблица ЙЦУКЕН ↔ QWERTY по позиции клавиши:

```
`→ё  ~→Ё
q→й  w→ц  e→у  r→к  t→е  y→н  u→г  i→ш  o→щ  p→з  [→х  ]→ъ
a→ф  s→ы  d→в  f→а  g→п  h→р  j→о  k→л  l→д  ;→ж  '→э
z→я  x→ч  c→с  v→м  b→и  n→т  m→ь  ,→б  .→ю  /→.
```

- Регистр сохраняется (Shift/CapsLock).
- Цифры и символы не конвертируются (остаются как есть).

## 5. Эвристика (LanguageDetector)

Для слова W, набранного в раскладке L:

1. Конвертируем W в другую раскладку → W′.
2. Считаем `score(W, язык L)` — насколько W похоже на слово языка L.
3. Считаем `score(W′, другой язык)`.
4. Если `score(W′)` высокий **и** `score(W)` низкий → слово набрано не в той раскладке.

### Оценка «русскости» (кириллица)

- Доля гласных (а, е, ё, и, о, у, ы, э, ю, я) — в русском тексте ~35–50%.
- Частотность букв (о, е, а, и, н, т — самые частые).
- Запрещённые паттерны: слово не начинается с ы/ъ/ь, нет 3+ одинаковых согласных подряд.

### Оценка «английскости» (латиница)

- Доля гласных (a, e, i, o, u, y).
- Частотность букв и типичные диграфы (th, he, in, er, an).
- Запрещённые паттерны: нет 4+ согласных подряд.

### Ключевая асимметрия

Когда русское слово набрано в английской раскладке, латинская последовательность выглядит «не по-английски» (например, «ghbdtn» — без гласных), а конвертированная кириллица «привет» — нормально. Эта разница и есть сигнал.

### Порог

Слово короче 3 символов не исправляем ретроактивно (слишком неоднозначно).

## 6. Гибридная стратегия срабатывания

### Проактивно (мгновенное переключение)

Если первый символ — клавиша, которая в целевой раскладке даёт очень частую букву, а в текущей — редкую (например, `j` → русская «о» — самая частая буква русского, а в английском `j` редкая), переключаем раскладку сразу. Консервативно: требуем 1–2 сильных сигнала, пороги настраиваемые в коде (в UI настроек для v1 нет).

### Ретроактивно (исправление по концу слова)

На границе слова (пробел, знак препинания, Enter) применяем эвристику. Если решено «не та раскладка» → TextFieldController заменяет слово, LayoutManager переключает раскладку.

## 7. Краевые случаи

| Случай | Обработка |
|---|---|
| Парольные поля | AX определяет secure-поля → пропускаем |
| Слова, валидные в обеих раскладках | Эвристика решает по разнице скоров; короткие слова не трогаем |
| Собственное поле приложения | Пропускаем (защита от зацикливания) |
| Цифры/символы в слове | Не конвертируются, но участвуют в границе слова |
| Caps Lock / Shift | Регистр сохраняется при конвертации |
| Приложение без AX-поддержки | Ничего не делаем (безопасный отказ) |

## 8. Разрешения

| Разрешение | Зачем | Проверка |
|---|---|---|
| Accessibility | Читать/заменять текст через AX API | `AXIsProcessTrusted()` |
| Input Monitoring | Перехватывать нажатия через CGEventTap | `CGPreflightListenEventAccess()` |

PermissionManager при первом запуске:
1. Проверяет оба разрешения.
2. Если нет — показывает диалог с инструкцией и кнопкой «Открыть настройки» (открывает нужную панель System Settings).
3. В menu bar меню — пункт «Разрешения» со статусом (✓/✗) и кнопкой перепроверки.

⚠️ После выдачи разрешения приложение нужно перезапустить (CGEventTap и AX-доверие применяются при старте). Показываем подсказку об этом.

## 11. Тестирование

### Юнит-тесты (чистые функции)

- **TextConverterTests:** двусторонняя конвертация, сохранение регистра, цифры/символы не трогаются, все 33 буквы.
- **LanguageDetectorTests:**
  - «ghbdtn» → русское «привет» (детект);
  - «руддщ» (hello в русской раскладке) → английское «hello» (детект);
  - «hello», «the», «world» → не трогаем;
  - «привет», «мир» → не трогаем;
  - короткие слова (<3 символов) → не трогаем;
  - слова с цифрами → не трогаем.

### Ручное тестирование (системные компоненты)

- Проверка в Terminal, Safari, TextEdit, Notes.
- Проверка парольных полей.
- Проверка переключения раскладки.

## 12. Критерии готовности (v1)

1. Русский текст, набранный в английской раскладке, исправляется автоматически.
2. Английский текст, набранный в русской раскладке, исправляется автоматически.
3. Работает в основных приложениях (Terminal, Safari, TextEdit).
4. Парольные поля не трогаются.
5. Переключатель вкл/выкл работает.
6. Юнит-тесты проходят.
