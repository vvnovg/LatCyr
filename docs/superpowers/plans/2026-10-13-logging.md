# Постоянное логирование с ротацией — План реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Файловый лог в `~/Library/Logs/LatCyr/` с ротацией по суммарному объёму (10/50/100 МБ), уровнем (выкл/ошибки/инфо/отладка), который переключается в меню, и маскированием набранного текста. Цель — чтобы поддержка находила причину проблемы по присланному файлу.

**Architecture:** Чистые части лежат отдельно от I/O и покрыты юнит-тестами: `LogLevel`/`LogSettings`, `LogRedactor`/`Sensitive`, `LogMessage`/`LogLine`/фасад `Log`, `LogRotation`. `FileLogger` пишет на собственной последовательной очереди, чтобы callback event tap'а не ждал диска. `LogController` связывает `Log` с `FileLogger`, хранит настройки и ведёт 30-минутный таймер захвата текста. `AppDelegate` строит подменю. Вызовы `Log.*` расставляются в `InputMonitor`, `TextFieldController`, `KeystrokeSimulator`, `LayoutManager` и в действиях меню.

**Tech Stack:** Swift Package (без Xcode), XCTest, Foundation (`FileHandle`, `UserDefaults`, `ISO8601DateFormatter`), AppKit (`NSMenu`, `NSWorkspace`).

**Спецификация:** `docs/superpowers/specs/2026-10-13-logging-design.md`

## Global Constraints

- Все комментарии в коде — на английском (текущий стиль репозитория). Тексты сообщений лога — на английском. Тексты меню — на русском.
- По умолчанию уровень `.off`. Пока логирование выключено, каталог `~/Library/Logs/LatCyr/` не создаётся и ничего не пишется.
- Допустимые лимиты: ровно `10`, `50`, `100` МБ (1 МБ = `1024 * 1024` байт). По умолчанию 100 МБ. Любое другое сохранённое значение читается как 100 МБ.
- Файлов не больше `5`: `latcyr.log`, `latcyr.1.log` … `latcyr.4.log`. `perFile = maxTotal / 5`.
- Набранный текст (слово, его конверсия, выделение, слово-исключение) передаётся в лог **только** через `Sensitive(...)`. Голая строковая переменная с пользовательским текстом в интерполяции `Log.*` — ошибка ревью.
- Флаг захвата текста не персистится, длится `30 * 60` секунд и доступен только при уровне ≥ `.info`.
- Никакого файлового I/O на вызывающем потоке: запись в файл идёт только в `FileLogger.queue`.
- `Log.error/info/debug` принимают `@autoclosure`. При уровне ниже нужного сообщение не строится.
- Отдельные нажатия клавиш не логируются.
- Поведение коррекции не меняется ни в одной ветке. Добавляются только вызовы `Log.*` и чисто эквивалентные перестройки `guard` ради указания причины.
- Режим event tap не меняется: `options: .defaultTap`, `place: .headInsertEventTap`.
- Коммиты — conventional style (`feat:`, `fix:`, `docs:`, `test:`). Каждый коммит заканчивается строкой `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

```swift
import Foundation

/// How much goes into the log file. Each level includes everything below it.
enum LogLevel: Int, Comparable, CaseIterable {
    case off = 0, error, info, debug

    static func < (lhs: LogLevel, rhs: LogLevel) -> Bool { lhs.rawValue < rhs.rawValue }

    /// Tag written into each log line.
    var tag: String {
        switch self {
        case .off: return "OFF"
        case .error: return "ERROR"
        case .info: return "INFO"
        case .debug: return "DEBUG"
        }
    }

    /// Menu title.
    var title: String {
        switch self {
        case .off: return "Выключено"
        case .error: return "Только ошибки"
        case .info: return "Информация"
        case .debug: return "Отладка"
        }
    }
}

/// Persisted logging settings: level and total size cap. The "capture typed
/// text" flag is deliberately not here — it must never survive a restart.
struct LogSettings {
    static let megabyte = 1024 * 1024
    static let allowedMaxTotalBytes = [10 * megabyte, 50 * megabyte, 100 * megabyte]
    static let defaultMaxTotalBytes = 100 * megabyte

    private static let levelKey = "logLevel"
    private static let maxTotalBytesKey = "logMaxTotalBytes"

    private let defaults: UserDefaults

    init(defaults: UserDefaults = .standard) {
        self.defaults = defaults
    }

    /// A missing key reads as 0, which is `.off` — the required default.
    var level: LogLevel {
        get { LogLevel(rawValue: defaults.integer(forKey: Self.levelKey)) ?? .off }
        nonmutating set { defaults.set(newValue.rawValue, forKey: Self.levelKey) }
    }

    /// Anything outside the allowed set (missing key, hand-edited plist,
    /// a value from a future version) reads as the 100 MB ceiling.
    var maxTotalBytes: Int {
        get {
            let stored = defaults.integer(forKey: Self.maxTotalBytesKey)
            return Self.allowedMaxTotalBytes.contains(stored) ? stored : Self.defaultMaxTotalBytes
        }
        nonmutating set {
            let value = Self.allowedMaxTotalBytes.contains(newValue) ? newValue : Self.defaultMaxTotalBytes
            defaults.set(value, forKey: Self.maxTotalBytesKey)
        }
    }
}
```

```swift
import Foundation

/// Replaces user text with what support actually needs to diagnose a
/// detection problem — its length and alphabet — so the log file never
/// becomes a record of what the user typed.
enum LogRedactor {
    static func redact(_ text: String) -> String {
        var hasCyrillic = false
        var hasLatin = false
        for ch in text where ch.isLetter {
            if ch.unicodeScalars.contains(where: { (0x0400...0x04FF).contains($0.value) }) {
                hasCyrillic = true
            } else {
                hasLatin = true
            }
        }
        let alphabet: String
        switch (hasCyrillic, hasLatin) {
        case (true, true): alphabet = "mix"
        case (true, false): alphabet = "cyr"
        case (false, true): alphabet = "lat"
        case (false, false): alphabet = "none"
        }
        return "[\(text.count) \(alphabet)]"
    }
}

/// User text headed for the log. Only `LogMessage`'s own interpolation may
/// print `text` as-is, and only while typed-text capture is on; every other
/// way of turning this into a string goes through `description`, which is
/// redacted. Safe by default: forgetting the capture check can't leak.
struct Sensitive: CustomStringConvertible {
    let text: String

    init(_ text: String) {
        self.text = text
    }

    var description: String { LogRedactor.redact(text) }
}
```

```swift
import AppKit

/// A log message. Its own string interpolation is the one place that may
/// print a `Sensitive` value unredacted — and only while typed-text capture
/// is on. Everything else interpolates as `String(describing:)`.
struct LogMessage: ExpressibleByStringInterpolation {
    let text: String

    init(stringLiteral value: String) {
        text = value
    }

    init(stringInterpolation: Interpolation) {
        text = stringInterpolation.result
    }

    struct Interpolation: StringInterpolationProtocol {
        var result = ""
        /// Read once per message, so a message is never half raw, half redacted.
        private let captureText = Log.captureText

        init(literalCapacity: Int, interpolationCount: Int) {
            result.reserveCapacity(literalCapacity * 2)
        }

        mutating func appendLiteral(_ literal: String) {
            result += literal
        }

        /// Non-generic, so it wins over the generic overload below.
        mutating func appendInterpolation(_ value: Sensitive) {
            result += captureText ? value.text : value.description
        }

        mutating func appendInterpolation<T>(_ value: T) {
            result += String(describing: value)
        }
    }
}

/// One line of the log file. Pure: the caller supplies the time and app.
enum LogLine {
    static func format(date: Date, level: LogLevel, app: String, message: String, timeZone: TimeZone = .current) -> String {
        // One event per line — support greps these files.
        let escaped = message
            .replacingOccurrences(of: "\r", with: "\\r")
            .replacingOccurrences(of: "\n", with: "\\n")
        return "\(timestamp(date, timeZone: timeZone)) \(level.tag) [\(app)] \(escaped)"
    }

    /// Building an ISO8601DateFormatter is expensive and this runs inside the
    /// event tap callback at debug level, so the common case is cached.
    private static var cachedFormatter = makeFormatter(timeZone: .current)

    private static func timestamp(_ date: Date, timeZone: TimeZone) -> String {
        let formatter = cachedFormatter.timeZone == timeZone ? cachedFormatter : makeFormatter(timeZone: timeZone)
        return formatter.string(from: date)
    }

    private static func makeFormatter(timeZone: TimeZone) -> ISO8601DateFormatter {
        let formatter = ISO8601DateFormatter()
        formatter.formatOptions = [.withInternetDateTime, .withFractionalSeconds]
        formatter.timeZone = timeZone
        return formatter
    }
}

/// Logging facade. All callers in this app run on the main thread, so the
/// static state needs no synchronization; file I/O happens behind `sink`
/// (FileLogger's own queue), never here.
enum Log {
    static var level: LogLevel = .off
    /// Typed-text capture. Never persisted — LogController owns its timer.
    static var captureText = false
    /// Receives fully formatted lines. nil means nowhere to write.
    static var sink: ((String) -> Void)?
    /// Overridable for tests.
    static var frontmostAppID: () -> String = {
        NSWorkspace.shared.frontmostApplication?.bundleIdentifier ?? "-"
    }

    /// `@autoclosure`: below the current level the message is never built,
    /// which is what makes debug calls in the event tap free when logging is off.
    static func error(_ message: @autoclosure () -> LogMessage) { emit(.error, message) }
    static func info(_ message: @autoclosure () -> LogMessage) { emit(.info, message) }
    static func debug(_ message: @autoclosure () -> LogMessage) { emit(.debug, message) }

    /// Environment lines at the top of each logging session. Written at any
    /// level except `.off`: version and permissions matter to support even
    /// when the user only logs errors.
    static func header(_ lines: [String]) {
        guard level != .off, let sink else { return }
        let date = Date()
        let app = frontmostAppID()
        for line in lines {
            sink(LogLine.format(date: date, level: .info, app: app, message: line))
        }
    }

    private static func emit(_ messageLevel: LogLevel, _ message: () -> LogMessage) {
        guard messageLevel <= level, let sink else { return }
        sink(LogLine.format(date: Date(), level: messageLevel, app: frontmostAppID(), message: message().text))
    }
}
```

```swift
import Foundation

/// Size-based rotation decisions, kept apart from the file I/O in
/// FileLogger so the part that guards the user's disk is unit-tested.
/// Files: latcyr.log (index 0, current), latcyr.1.log … latcyr.4.log
/// (higher index = older).
enum LogRotation {
    static let fileCount = 5

    static func perFileLimit(totalLimit: Int) -> Int {
        totalLimit / fileCount
    }

    /// Whether to rotate before appending `incoming` bytes. An empty file
    /// never rotates: a single line longer than the per-file limit is
    /// written whole into a fresh file rather than rotating forever.
    static func shouldRotate(currentSize: Int, incoming: Int, perFileLimit: Int) -> Bool {
        currentSize > 0 && currentSize + incoming > perFileLimit
    }

    /// Rotated files to delete so the total fits `totalLimit`, oldest first.
    /// Needed beyond normal rotation when the user lowers the limit: files
    /// written under the old, larger per-file limit would otherwise stay.
    static func filesToDelete(currentSize: Int, rotated: [Int: Int], totalLimit: Int) -> [Int] {
        var total = currentSize + rotated.values.reduce(0, +)
        var result: [Int] = []
        for index in rotated.keys.sorted(by: >) {
            guard total > totalLimit else { break }
            result.append(index)
            total -= rotated[index] ?? 0
        }
        return result
    }
}
```

```swift
import Foundation

/// Thin wrapper over the log files on disk. Every file operation runs on a
/// private serial queue: the event tap is an active tap, so the system
/// waits for its callback on every keystroke — a disk write there would
/// stall typing. Callers only format a line and enqueue it.
final class FileLogger {
    static var defaultDirectory: URL {
        FileManager.default.homeDirectoryForCurrentUser.appendingPathComponent("Library/Logs/LatCyr")
    }

    let directory: URL
    private let queue = DispatchQueue(label: "com.latcyr.log", qos: .utility)

    // State below is touched only on `queue`.
    private var handle: FileHandle?
    /// Kept in memory so a write never needs a stat.
    private var currentSize = 0
    private var maxTotalBytes: Int
    /// Set when the file can't be opened or written. There is nowhere to
    /// report the logger's own failure, so it goes quiet until `close()`
    /// (called on every level change) clears the latch and allows a retry.
    private var failed = false

    init(directory: URL = FileLogger.defaultDirectory, maxTotalBytes: Int) {
        self.directory = directory
        self.maxTotalBytes = maxTotalBytes
    }

    var currentFileURL: URL { url(forIndex: 0) }

    func write(_ line: String) {
        let data = Data((line + "\n").utf8)
        queue.async { [self] in
            guard openIfNeeded() else { return }
            let perFile = LogRotation.perFileLimit(totalLimit: maxTotalBytes)
            if LogRotation.shouldRotate(currentSize: currentSize, incoming: data.count, perFileLimit: perFile) {
                rotate()
                guard openIfNeeded() else { return }
            }
            do {
                try handle?.write(contentsOf: data)
                currentSize += data.count
            } catch {
                closeHandle()
                failed = true
            }
        }
    }

    /// Applies a new total cap right away, deleting what no longer fits —
    /// lowering 100 MB to 10 MB must free the disk now, not after a while.
    func setMaxTotalBytes(_ bytes: Int) {
        queue.async { [self] in
            maxTotalBytes = bytes
            enforceLimits()
        }
    }

    /// Closes the current file (it reopens lazily on the next write) and
    /// clears the failure latch. Existing files are kept: they may not have
    /// been sent to support yet.
    func close() {
        queue.async { [self] in
            closeHandle()
            failed = false
        }
    }

    /// Blocks until every queued operation has run. For app termination and tests.
    func flush() {
        queue.sync {}
    }

    // MARK: - Private (queue only)

    private func url(forIndex index: Int) -> URL {
        directory.appendingPathComponent(index == 0 ? "latcyr.log" : "latcyr.\(index).log")
    }

    private func openIfNeeded() -> Bool {
        if handle != nil { return true }
        if failed { return false }
        let fileManager = FileManager.default
        let url = currentFileURL
        do {
            try fileManager.createDirectory(at: directory, withIntermediateDirectories: true)
            if !fileManager.fileExists(atPath: url.path) {
                fileManager.createFile(atPath: url.path, contents: nil)
            }
            let opened = try FileHandle(forWritingTo: url)
            currentSize = Int(try opened.seekToEnd())
            handle = opened
            return true
        } catch {
            failed = true
            return false
        }
    }

    private func closeHandle() {
        try? handle?.close()
        handle = nil
    }

    private func rotate() {
        closeHandle()
        let fileManager = FileManager.default
        try? fileManager.removeItem(at: url(forIndex: LogRotation.fileCount - 1))
        for index in stride(from: LogRotation.fileCount - 2, through: 0, by: -1) {
            let from = url(forIndex: index)
            if fileManager.fileExists(atPath: from.path) {
                try? fileManager.moveItem(at: from, to: url(forIndex: index + 1))
            }
        }
        currentSize = 0
    }

    private func enforceLimits() {
        let perFile = LogRotation.perFileLimit(totalLimit: maxTotalBytes)
        if fileSize(forIndex: 0) > perFile { rotate() }
        var rotated: [Int: Int] = [:]
        for index in 1..<LogRotation.fileCount where FileManager.default.fileExists(atPath: url(forIndex: index).path) {
            rotated[index] = fileSize(forIndex: index)
        }
        let doomed = LogRotation.filesToDelete(currentSize: fileSize(forIndex: 0), rotated: rotated, totalLimit: maxTotalBytes)
        for index in doomed {
            try? FileManager.default.removeItem(at: url(forIndex: index))
        }
    }

    private func fileSize(forIndex index: Int) -> Int {
        if index == 0, handle != nil { return currentSize }
        let attrs = try? FileManager.default.attributesOfItem(atPath: url(forIndex: index).path)
        return (attrs?[.size] as? NSNumber)?.intValue ?? 0
    }
}
```

```swift
import Foundation

/// Owns the logging runtime: wires `Log` to the file, persists level and
/// size, and runs the typed-text capture timer. Main thread only.
final class LogController {
    static let captureDuration: TimeInterval = 30 * 60

    private let settings: LogSettings
    private let fileLogger: FileLogger
    private var captureTimer: Timer?
    /// Called on the main thread when capture switches itself off, so the
    /// menu can drop its checkmark.
    var onCaptureExpired: (() -> Void)?

    init(settings: LogSettings = LogSettings(), fileLogger: FileLogger? = nil) {
        self.settings = settings
        self.fileLogger = fileLogger ?? FileLogger(maxTotalBytes: settings.maxTotalBytes)
    }

    var level: LogLevel { settings.level }
    var maxTotalBytes: Int { settings.maxTotalBytes }
    var isCapturingText: Bool { Log.captureText }
    var logFileURL: URL { fileLogger.currentFileURL }
    var logDirectory: URL { fileLogger.directory }

    /// Call once at launch. `header` is evaluated only when logging is on.
    func start(header: () -> [String]) {
        let fileLogger = self.fileLogger
        Log.sink = { line in fileLogger.write(line) }
        Log.level = settings.level
        fileLogger.setMaxTotalBytes(settings.maxTotalBytes)
        if Log.level != .off {
            Log.header(header())
        }
    }

    func setLevel(_ newLevel: LogLevel, header: () -> [String]) {
        let old = Log.level
        guard newLevel != old else { return }
        if newLevel < .info { setCapturingText(false) }
        // Logged under the old level: records a switch *down* (including to off).
        Log.info("log level \(old.tag) -> \(newLevel.tag)")
        settings.level = newLevel
        Log.level = newLevel
        if newLevel == .off {
            fileLogger.close()
            return
        }
        if old == .off {
            // close() also clears FileLogger's failure latch, so turning
            // logging back on retries a file that previously failed to open.
            fileLogger.close()
            Log.header(header())
        }
        // Logged under the new level: records a switch *up* from below info.
        if old < .info {
            Log.info("log level \(old.tag) -> \(newLevel.tag)")
        }
    }

    func setMaxTotalBytes(_ bytes: Int) {
        settings.maxTotalBytes = bytes
        fileLogger.setMaxTotalBytes(settings.maxTotalBytes)
        Log.info("log size limit \(settings.maxTotalBytes / LogSettings.megabyte) MB")
    }

    /// Turning it on (re)starts the 30-minute timer. Refused below `.info`:
    /// at the error level no message carries typed text anyway.
    func setCapturingText(_ requested: Bool) {
        let on = requested && Log.level >= .info
        captureTimer?.invalidate()
        captureTimer = nil
        if on {
            let timer = Timer(timeInterval: Self.captureDuration, repeats: false) { [weak self] _ in
                self?.setCapturingText(false)
                self?.onCaptureExpired?()
            }
            // .common: keep counting while the status menu is open.
            RunLoop.main.add(timer, forMode: .common)
            captureTimer = timer
        }
        guard on != Log.captureText else { return }
        Log.captureText = on
        Log.info(on ? "typed text capture ON for \(Int(Self.captureDuration / 60)) min" : "typed text capture OFF")
    }

    /// Lets queued lines reach the disk before the app exits.
    func flush() {
        fileLogger.flush()
    }
}

Неприменённая коррекция на ретроактивном пути — `error`, на проактивном — `debug` (за ним всегда стоит ретроактивная проверка).
```
